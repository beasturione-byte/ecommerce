=========================================================
      COMANDOS DEL PROYECTO E-COMMERCE (DJANGO)
=========================================================

1. CONFIGURACIÓN INICIAL Y ENTORNO VIRTUAL
---------------------------------------------------------
# Crear el entorno virtual
python -m venv venv

# Activar el entorno virtual (PowerShell en Windows)
.\venv\Scripts\activate

# Instalar Django
pip install django

# Guardar las dependencias en un archivo (Excelente para el portafolio)
pip freeze > requirements.txt


2. CREACIÓN DEL PROYECTO (Solo como referencia, ya ejecutados)
---------------------------------------------------------
# Iniciar proyecto y aplicación
python -m django startproject config .
python manage.py startapp tienda


3. BASE DE DATOS Y MIGRACIONES
---------------------------------------------------------
# Preparar los modelos para la base de datos
python manage.py makemigrations

# Aplicar los cambios y crear las tablas
python manage.py migrate

# Crear el usuario administrador (Pedirá nombre, email y clave)
python manage.py createsuperuser


4. EJECUCIÓN DEL PROYECTO
---------------------------------------------------------
# Levantar el servidor de desarrollo
python manage.py runserver

# (El servidor estará disponible en http://127.0.0.1:8000/)
# Para detener el servidor, presiona: Ctrl + C en la terminal
